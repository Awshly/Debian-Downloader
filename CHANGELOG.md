# Changelog

## 0.1.0 — initial development release

- Bash-based Debian installer ISO downloader.
- HTTPS-only downloads with progress and resumable partial files.
- Signed SHA-512 manifest and ISO checksum verification.
- README, MIT license, smoke tests, and GitHub Actions CI.
- Live ISO support is URL-driven in this first version; automatic live-index discovery is on the roadmap.
